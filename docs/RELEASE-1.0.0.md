# Release v1.0.0 — SILTGOV Demo

## Highlights

- Frontend demo multi-rol (Superusuario, Administrador, Liquidador, Pagador) listo para portfolio.
- Accesibilidad: skip link, tooltips Radix, verificación automatizada de nombres en botones.
- CI verde: ESLint, Vitest, build Vite en GitHub Actions.
- Documentación: arquitectura objetivo, OWASP/ISO 25010, reportes `.ai` en `docs/`.
